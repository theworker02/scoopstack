# scoopstack

Scoop and reshape stack text streams with deterministic transforms.

**Site:** https://theworker02.github.io/scoopstack/

## Install / run

```bash
git clone https://github.com/theworker02/scoopstack.git
cd scoopstack
node src/cli.js
node --test
```
